01 PDF — hapus proteksi

Untuk PDF yang bisa dibuka tanpa password tapi dibatasi print/copy/edit. Tool ini merender ulang setiap halaman menjadi PDF baru tanpa enkripsi. Jika PDF meminta password untuk membuka, masukkan password itu di kolom di bawah — tool ini tidak bisa menebak/membobol password yang tidak diketahui.

Klik atau seret file .pdf ke sini (bisa pilih beberapa sekaligus)
Catatan: hasil berupa PDF baru berbasis gambar per halaman (tampilan identik), sehingga teks tidak lagi bisa di-select/copy secara langsung. Ini trade-off yang diperlukan agar proteksi benar-benar hilang. Kalau pilih lebih dari 1 file sekaligus, semua hasil digabung jadi satu file ZIP untuk diunduh.

02 Word (.docx) / Excel (.xlsx) — hapus proteksi

Menghapus pengaturan "Restrict Editing" (Word) atau "Protect Sheet/Workbook" (Excel) dari file yang tidak dikunci password untuk dibuka. Jika file dienkripsi penuh dengan password buka, tool ini akan memberi tahu Anda bahwa itu di luar kemampuannya.

Klik atau seret file .docx / .xlsx ke sini (bisa pilih beberapa sekaligus)

01 Pilih arah konversi

Klik atau seret file ke sini
Catatan kualitas hasil: konversi PDF→Word mengekstrak teks polos (tanpa tata letak/gambar asli). Konversi Word→PDF mengikuti tampilan render HTML sehingga format kompleks (tabel rumit, kolom) bisa sedikit berbeda dari aslinya. Untuk dokumen penting dengan format rumit, cek kembali hasilnya sebelum dipakai. Bisa pilih beberapa file sekaligus (kecuali Gambar→PDF yang memang selalu digabung jadi 1 PDF) — hasilnya otomatis dibungkus jadi satu file ZIP kalau lebih dari 1 file.
